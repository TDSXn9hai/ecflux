# 阶段1 v2：敏感度主指标校验（2026-11-11，标签已由用户确认）

结论先行：
- **在你确认的标签下，单一指标里没有明显的赢家。**
  - HPSv2、单步速度场 MSE、轨迹速度场 MSE 和人工严重程度的 Spearman 相关分别为 0.84、0.83、0.82。只有 18 个配置时，Spearman 的抽样误差约 ±0.1，这三个数在误差范围内没有差别。
  - FID 为 0.53，CLIP 为 0.28，明显落后。这验证了你的判断：FID 不适合作为主指标。
- **速度场指标和 HPSv2 各有对方漏掉的退化**，两者互补：
  - 速度场指标漏掉了 G5 r0.1 的早期扭曲。
  - HPSv2 漏掉了 G4 r0.2 的直线弯曲，以及 G6 的模糊发灰。
- **建议 APRA 用双闸门**：轨迹速度场 MSE 和 HPSv2（200 条 prompt）各设一个阈值，任意一个超标就判这一轮退化超标。这个规则在 18 个配置上的 Spearman 为 0.88，和人工标签最一致。不过这是用同一批标签挑出来的组合，差距同样在 ±0.1 以内，只能作为倾向性证据。
- **组敏感度和表1的初始剪枝率不一致**：G5 在 r0.1 就接近 2 级，是除 G1 外最敏感的组，但表1给它的初始剪枝率是 0.25，在各组里排第二高。G2 和 G3 在 r0.3 时仍为 0 级。stage2 应调整各组的初始值和上限。

## 1. 实验设置
- 模型：FLUX.2 Klein 4B Base。生成设置为 512px、20 步、CFG 4.0、seed 42，batch 1，每条 prompt 都用同一个初始噪声，和旧阶段1相同。
- 敏感度实验：G1–G6 每组单独剪 0.1 / 0.2 / 0.3，共 18 个配置，不做恢复训练。
- 剪枝判据复现旧阶段1：头用梯度敏感度（Double Block 也用梯度），神经元用激活 L1，文本注意力占比不去掉 padding，跨模态阈值取 1.0。实现见 `scripts/run_stage1.sh` 里的 `V1_CRITERIA`。
- 与旧版核对：G1 r0.2 同样剪掉了 double:0 的 head 18；参数比例一致（例如 G1 r0.2 为 0.976）。
- 候选指标，都是"越大越差"：
  - `vel_mse`：单步速度场 MSE×100。在训练集的 16 个随机 (x_t, t) 上，比较剪枝模型和未剪枝模型的速度场。这是原来的代理指标。
  - `traj_vel_mse`（新增）：轨迹速度场 MSE×100。先用未剪枝模型对 D_val 前 32 条 prompt 做 CFG 采样，记录每一步的 x_t；再在这些 x_t 上比较 CFG 合成后的速度场，20 步取平均。
  - `d_hps` / `d_hps200`：HPSv2.1 下降量，分别用 D_val 全部 1000 张和前 200 张。计算时对同一 prompt、同一 seed 的图成对比较。
  - `d_fid` / `d_clip`：D_val 1000 张上的 FID 上升量和 CLIP 下降量。
- 种子波动：未剪枝模型用 seed 42/43/44 各生成 1000 张。

| 未剪枝 4B（D_val 1000） | seed 42 | 43 | 44 | σ |
|---|---|---|---|---|
| FID | 61.95 | 61.01 | 61.86 | 0.52 |
| CLIP | 27.73 | 27.74 | 27.75 | 0.012 |
| HPSv2 | 0.2825 | 0.2809 | 0.2819 | 0.00078 |

D_val 的 FID 基线从旧版的 73.47 变成了 61.95，原因是 pexels 数据重新下载后，`val_prompts.txt` 和参考图都变了，所以 v2 的数值不能和旧报告直接比较。

### 每个指标漏掉的配置（数值见 `summary.json`、`fig_rank_table_visual_labels_v2.png`）
- **四个指标都把 G2 r0.3 排得偏高**。它在人工标签里是 0 级，但 traj 为 9.0、ΔHPS 为 0.0116、vel 为 1.02，在 0 级配置里都是最大值。G2 剪枝后构图变化较大，但画质没有变差。偏离原模型不等于变差，这是所有"和原模型比"的指标共有的局限。HPS 也会因为构图变化而波动。
- **FID**：看不到 G5 的退化。G5 r0.2 的 ΔFID 为 −0.50，比未剪枝还好；G4 r0.2 为 +0.45，G6 r0.2 为 +0.30，都在 1σ 以内。FID 只对 G1 这种崩溃式退化敏感。
- **HPSv2**：
  - 看不到 G4 r0.2 的结构异常。它的 ΔHPS 为 0.0036，比 0 级的 G2 r0.2（0.0053）还低。
  - 对 G6 的模糊发灰不敏感。G6 r0.3 为 0.0110，低于 G2 r0.3 的 0.0116。
  - 对 G5 和 G1 的人脸、物体扭曲很敏感。G5 r0.1 为 0.0076，在 r0.1 各组里最高。
- **轨迹速度场 MSE**：
  - 漏掉了 G5 r0.1。它的值为 4.1，和 0 级的 G4 r0.1（4.3）、G6 r0.1（3.8）相当。
  - G6 r0.2 为 8.2，低于 G2 r0.3 的 9.0。
  - 对 G1、G4 的结构性退化很敏感：G4 r0.2 为 11.3，高于所有 0 级配置。
  - 0 级与 ≥2 级之间的间隔最大，为 5.3σ。
- **单步速度场 MSE**：网络末端的 G6 输出幅度大，所以 G6 的数值被放大。G6 r0.1 为 0 级，值却是 2.14，比 1.5 级的 G4 r0.2（1.56）还大。它碰巧在 G5 r0.1 上表现不错（0.92），但这是尺度偏差带来的，不能作为依据。
- `fig_traj_per_step.png` 显示了各组误差在采样步上的分布：
  - G1 的误差集中在第 3–9 步（中高噪声、决定构图的阶段），r0.2 时峰值约 120，是其他组峰值的 7 倍以上。

  - G6 的误差在首尾两端偏高，最后一步约 13，对应细节和色调阶段。

## 4. 建议
1. **APRA 反馈改为双闸门**：每轮评估 `traj_velocity_mse`（32 条 prompt，84s）和 `hps`（200 条，约 9min），各设 low/high 阈值，任意一个超过 high 就回滚。
   - 理由：两者的漏检互补。HPS 管人脸和物体扭曲（G5），轨迹速度场管结构和线条（G4）。不需要拟合组合权重，单次评估约 10 分钟，是 FID（46 分钟）的 1/4。
   - 不选 rank 组合：它需要一组参照配置才能算排名，放进 APRA 循环不方便。
   - 不选单步速度场：它对各组的尺度不一致。
2. **阈值要在恢复训练之后重新标定**。轨迹速度场 MSE 衡量的是"和未剪枝模型差多少"，用 pexels 做恢复训练后，即使画质没有变差，这个值也会上升。HPS 也会受训练集风格影响（旧 stage2 已经出现过）。所以本节的无恢复训练 σ 不能直接拿来当阈值，需要先用 `full` 的两次重复运行，估计"一轮剪枝加恢复训练"的运行间波动，再把阈值定为 low≈1σ、high≈3σ。
3. **调整表1的初始剪枝率**。根据本次敏感度结果：
   - G5 的 0.25 → 约 0.05–0.08。
   - G2、G3 可以提高到 0.2–0.25。
   - G6 的 0.35 偏高，r0.2 已是 1.5 级。
   - G1 保持最保守。
   - 具体数值等阈值标定后，由 APRA 自己调节；这里只改初值和上限。
4. **FID 只用于最终表格**，不进入 APRA 循环。

## 5. 重要性统计（`importance/`）
- 这部分使用当前 `configs/prune.yaml` 的判据，即 stage2 的设置：Double 头逐头删除、神经元权重大小、去掉 padding、跨模态取文本占比前 25%。
- 两组校准种子之间，头重要性排序的 Spearman 均值为 0.94（最低层 0.83），文本占比为 0.99。神经元用权重大小打分，与校准数据无关，所以相关为 1.0。
