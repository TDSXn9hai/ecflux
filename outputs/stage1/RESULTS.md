# 阶段1 结果说明（2026-10-31）

设置：FLUX.2 Klein 4B Base，512px，20 步，CFG 4.0，seed 42。D_val 共 1000 条，FID 基线 73.47，3 个种子的 FID 标准差 σ=0.73（见 `outputs/stage0/fidvar/summary.json`）。

## 1.1 重要性统计（`importance/`）
- **稳定性**：用两组校准种子分别统计，排序的 Spearman 相关为：注意力头 0.96（最低层 0.86），神经元 0.98，文本注意力占比 0.995。32×2 的校准量足够。
- **跨模态头**：阈值 `cross_ratio_threshold=1.0` 下，600 个头中有 324 个被判为跨模态头，集中在 Single Block 中段（single 7、8、10 为 24/24），Double Block 每层只有 1 到 7 个。这个分布和"Double Block 负责文本绑定"的假设不符。一个待核实的可能原因：文本序列被 padding 到 512，可能把 padding token 也算进了文本注意力质量。阶段2前需要先修正统计（加 attention mask），或改用分位数定阈值。
- **FFN 激活稀疏度**（激活低于本层最大值 5% 的神经元占比）：G1 13%，G2 48%，G3 33%，G4 4%，G5 9%，G6 18%。
- **相邻 Single Block 相似度**：τ 取 0.88、0.90、0.92、0.94 时，超过阈值的块对数分别为 15、12、6、4。τ=0.92 时这 6 对是 0:1、5:6、6:7、7:8、8:9、12:13。

## 1.2 逐组敏感度（`sens/`，单组剪枝，无恢复训练）
各组 ΔFID（括号内为 velocity MSE×100）：
- G1：r=0.1 时 +4.37（0.57）；r=0.2 时 **+269，生成结果是噪声图**（3.76）；r=0.3 时 +276
- G2：+0.79 / +0.23 / +1.46
- G3：+0.71 / +0.05 / −0.38
- G4：+0.40 / +0.01 / +4.20
- G5：−0.81 / −1.39 / −0.48
- G6：+0.74 / +1.97 / +4.12（velocity MSE 分别为 1.2 / 13.3 / 25.9）

结论：
1. **G1 最敏感**，符合表1把它设为最保守组的设定。G2 和 G3 在不超过 0.3 的剪枝率下，ΔFID 都在 2σ 以内，冗余比表1的初始值 0.10/0.15 所对应的要多。G5 在 0.3 时仍无可测退化。G4 和 G6 在 0.3 时开始退化（+4.2）。
2. **G1 崩溃的定位**（`sens_diag/summary.json`）：
   - 只剪神经元时 velocity MSE 为 0.19，只剪头时为 3.79，说明问题出在剪头。
   - 只剪 double:0 的头为 3.65，只剪 double:1 的头为 0.18，问题集中在 double:0。
   - 在 double:0 里每次只删一个头，删 **head 18** 一个头的 velocity MSE 就达到 2.65。
   - 这个头的文本注意力占比只有 0.09，梯度敏感度排倒数第 3，所以梯度判据选错了剪枝对象。同样剪 4 个头时，随机选的 velocity MSE 是 1.52，权重幅值判据是 2.44，都比梯度判据（3.79）好。
   - 建议：Double Block 只有 120 个头，可以改用"逐头删除后的 velocity MSE"作为评分，或者保护 double:0。
3. **velocity MSE 和 FID 的排序不一致**：G6 的 velocity MSE 最大，但 FID 退化不大；G1 r=0.2 的 velocity MSE 只有 3.8，FID 却已经崩溃。所以 velocity MSE 不能代替 FID 作为 APRA 的反馈信号，最多只能用于粗调参数。

## 1.3 APRA 调通（`apra_debug/`，velocity_mse，2 轮，每轮恢复 200 步）
- **流程跑通**：第1轮后参数比例为 0.840，块剪枝删除了 single 6、8、13，最终 3.876B → 2.960B。DiT 20 步延迟 2.26s，峰值显存 14.3GB。
- **修复了一个 bug**：FFN 剪枝后保留维度不是 8 的倍数时，恢复训练的反向传播会在 SDPA 报 misaligned address。现在已改为保留维度对齐到 8 的倍数，新增配置项 `prune.neuron_align=8`。
- **耗时**：恢复训练每步约 3.1–3.5s（grad_accum=4，测量时和其他任务共用一张卡），2000 步约 1.8h。单次 D_val FID（生成 1000 张）单卡约 45min。完整 APRA（5 轮 + 块剪枝）单卡约 15h；阶段2若有约 12 组消融，4 张卡约需 2 天。
- **机制问题**：第1轮 Δ 超过上阈值后，γ 被下调到 ×0.8，但已经剪掉的结构不会恢复，所以第2轮实际没有再剪。另外阈值 0.5/2.0 是按 FID 尺度定的，换代理指标时不能直接沿用。结合 σ=0.73，建议阈值改成 low≈1σ、high≈3σ，并决定退化超标时用 `apra.rollback=true` 回滚，还是只冻结该组不再增大剪枝率。
